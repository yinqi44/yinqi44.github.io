Bing 验证一键助手

把 Bing 给的验证内容粘进来，点一下就跳到已经填好的 GitHub 页面，你只要点 Commit。

粘贴后这里会显示将要创建的文件名和内容
操作步骤
  1. 在 Bing 站长平台验证方式里选 XML 文件，下载 BingSiteAuth.xml，用记事本打开，把内容整段复制
  2. 粘到上面输入框 → 点绿色按钮 → 会打开 GitHub 新建文件页，文件名和内容已经填好
  3. 拉到页面最下方点 Commit changes
  4. 等 1 分钟，回 Bing 点 VERIFY
  5. 验证通过后，左侧菜单 Sitemaps → 提交 sitemap.xml
  6. 自查：浏览器打开 https://yinqi44.github.io/BingSiteAuth.xml，能看到 XML 内容就说明放对了
另一种更省事的方式：Bing 验证选项里也能选 Meta 标签，它会给你一行 <meta name="msvalidate.01" content="...">。把那行发给我，我告诉你要粘到 index.html 的哪个位置。
